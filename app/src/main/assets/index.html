Kenapa dari WebIntoApp Sinar IR Tidak Keluar?
Infinix Note 60 Pro Abang punya sensor IR Blaster fisik, tetapi pembuat APK instan seperti WebIntoApp tidak menyertakan kode Java ConsumerIrManager.transmit() dan izin TRANSMIT_IR di dalam APK-nya.

Supaya lampu IR Infinix Note 60 Pro menyala saat tombol ditekan, APK harus di-build dengan jembatan Java Android.transmitIR(freq, pattern) yang sudah saya siapkan di aplikasi ini.
